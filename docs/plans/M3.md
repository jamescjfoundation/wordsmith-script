# M3 plan: writing aids

Date: 2026-11-19

## Scope

From the kickoff: autocomplete over the six lists in the spec (lists fill from
the script, can be edited, can be rebuilt, and can be switched off per list;
suggestions never auto-insert: Tab or Enter accepts, and typing on ignores);
spelling with craft-proof, ignoring character names and scene intros; find
and replace; normal, page and speed views; dark theme, typewriter scrolling
and focus mode.

Spec items (`docs/SPEC.md`):

| --- | --- |

Spelling data: the project owner chose craft-proof's built-in public-domain
Moby word list and modern-word supplement, plus the system's Hunspell English
dictionary where installed. SCOWL is not shipped (decision 0014).

## Approach

1. **`m3/autocomplete`** (`wordsmith-script::autocomplete`). Lists live in
   `app_data` (undoable, per script) with an on/off switch, entries and an
   order per list. Where the caret is decides the list: a Character's name or
   its extension in brackets; a Scene Heading's intro, location or time by
   its separators; a Transition. Lists learn a term when the writer leaves
   the paragraph. Commands to suggest, accept, add, remove, rename, switch,
   reorder, set options and rebuild. In the editor a small list appears
   beside the caret; Tab or Enter accepts the highlighted entry, Up and Down
   move through it, Escape hides it, and typing on simply narrows or ignores
   it. Nothing is ever inserted without a key press.
2. **`m3/spelling`** (`wordsmith-script::spelling`). Each paragraph is checked
   with craft-proof, skipping Character names (and their extensions), Scene
   Heading intros and anything on the script's ignore list. Commands to list
   issues, suggest, ignore and add words (the script's own word list in
   `app_data`). The page view underlines issues.
3. **`m3/find`**: find next and previous, find all, replace one and replace
   all (one undo step), with match case and whole word; a find bar in the
   editor.
4. **`m3/views`**: normal view (the script laid out continuously, no page
   edges, no page marks), page view (M2), and speed view (continuous, every
   element at the left margin with its name in a gutter, for fast typing);
   dark theme (dark interface and dark pages); typewriter scrolling (the
   caret's line stays at the same height on screen); focus mode (menus,
   toolbar and status bar hidden). All are commands.

Decisions to record: spelling data (0014), autocomplete rules and the
suggestion UI (0015), the views (0016).

## Tests

- Autocomplete: which list applies at each caret position; prefix matching;
  each order; learning on leaving a paragraph; rebuild; switching a list off;
  options (extension on Tab, next-speaker guess); accept replaces only the
  typed prefix; nothing changes without accept; hostile list data.
- Spelling: misspellings found in Action and Dialogue; character names and
  scene intros skipped; ignore and add-word; suggestions.
- Find and replace: case, whole word, across paragraphs, replace all as one
  undo step, element casing kept on replace.
- Views: each view lays out and maps the caret; speed view keeps text; dark
  pages render; editor headless tests for the suggestion keys and focus mode.
