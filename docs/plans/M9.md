# M9 plan: editing

Date: 2026-11-20

## Scope

SPEC-2 3.1, 3.2, 10 and 14, from `docs/plans/v0.2.md`: the Sequence element and
structure ranks; the Return/Tab hint in the status bar; reset to element; toggle
case; smart quotes and sentence capitals as options with an abbreviations list;
select scene; page breaks; new scenes; Go To (page, scene, bookmark, label);
bookmarks and labels; find limited to an element; the reformat tool; the format
checker.

## Approach

Everything is a command in `wordsmith-script` (so the palette, CLI and MCP get it),
with windows in `wordsmith-ui::tools`:

- `element.sequence`, `ElementKind::structure_rank`; outline elements on
  Mod+Shift+1 to 7.
- `element.hint`, `element.reset`, `text.toggleCase`, `select.scene`,
  `text.pageBreak`, `scene.insert`, `paragraph.delete/next/previous`,
  `goto.page`, `goto.scene` (`commands/editing.rs`).
- `typing.*` (`typing.rs`): off by default (decision 0031).
- `bookmark.*` (`bookmarks.rs`): the bookmark is a paragraph property, written as
  ` bookmark=N` on the native `@` line.
- `check.*` (`checker.rs`): five rules, three fixable, a before-printing setting.
- `find.*` take `elements`.

Decision to record: 0031.

## Tests

Each command has unit tests (bookmarks follow their paragraph through inserts and
splits; checker rules and fixes undo; toggle case keeps runs; page breaks split and
toggle; Go To by number and label); the windows are driven headlessly in
`wordsmith-ui` tests.

Status: done (2026-11-20). Pasting text with unknown element types is not built:
the clipboard carries plain text only, so there are no element types to add.
