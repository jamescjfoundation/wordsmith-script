# M18 plan: the File page

Date: 2026-11-20. Part of `docs/plans/v0.3-ui.md`.

Deliverables: the File tab opens a full-window page (`backstage.rs`) with a column
of pages:

- **New:** recent scripts, the templates as cards with previews by category, an
  empty script or a new tab, first steps.
- **Open:** Open, Import, the recent list with paths, recovery.
- **Save:** where the file is; Save, Save As, Save as Template, Revert, Close Tab.
- **Export:** every format, the story board and the cards.
- **Print:** the print choices inline (range, pages, set, sides, copies, collation,
  order, title page, marks) with Print, Preview and Save as PDF.
- **Compare.**
- **Preferences** and **Keys**: the same contents as their windows.
- **About.**

Escape or Back returns to the script. The Welcome window, New from Template,
Preferences, Keys, About and Print now open these pages; the app starts on New
when no script opens.

Tests: every page draws; Escape returns; templates start from New; the old
commands open their pages; every File-page command is registered; offscreen shot
checked by eye.

Status: done (2026-11-20). Live page thumbnails on the Print page are not built
(Preview opens the pages instead).
