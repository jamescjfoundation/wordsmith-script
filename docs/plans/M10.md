# M10 plan: macros and formatting

Date: 2026-11-20

## Scope

SPEC-2 3.2, 5 and 6: macros (twenty slots with name, shortcut, element, text,
element after, alias with its options, the elements it works in, copying from
another script, a starter set); the remaining text styles; a highlighter palette
and any color; text color; element settings for color, highlight, strike and
small letters; applying the template's formatting to every element.

## Approach

- `macros.rs`: `macro.list/set/clear/run/expand/copyFrom`; `macro.copyFromFile`
  and `macro.copyFromPath` in `wordsmith-format` read the other script. Aliases
  are checked when a word break is typed (one character), never on paste.
- `commands/format.rs`: `format.bold/italic/underline` (Mod+B/I/U),
  `format.style`, `format.plain`, `format.highlight`, `format.color`,
  `format.lowercase`, `format.state`.
- Native format 4 keeps the new styles (`{s…}…{/s}`).
- `element.configure` takes `strike`, `lowercase`, `color`, `highlight`;
  `element.applyTemplate`.
- Windows: Macros (Tools), alias confirmation; Format › Text Style, Highlight,
  Text Color menus; new fields in Element Settings.

Decision to record: 0032.

## Tests

Starter macros write headings, times and transitions; a Parenthetical macro fills
its brackets; aliases expand with matching capitals and ask first when set;
bad slots, elements and shortcuts are refused; copying drops unknown elements;
hostile stored macros are bounded. Every style toggles on a selection and at a
caret; highlight and color by name and hex; the native format round-trips every
new style and reads version 3 files. Macro keys and Mod+B in a headless window.

Status: done (2026-11-20). The indent rule is unchanged (decision 0032).
