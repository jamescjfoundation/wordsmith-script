# M5 plan: structure views

Date: 2026-11-19

## Scope

From the kickoff: title page editor and output; headers and footers with
scene, page, date and revision fields; index cards, one per scene, where
reordering cards reorders the script; scene view; a tables panel with scenes
and characters tables, where editing a cell edits the script and rows reorder,
plus CSV export; notes attached to text; character rename everywhere.

Spec items (`docs/SPEC.md`, "Views, outlining, navigation and notes" and
"Document model and elements"):

## Approach

1. **`m5/title-page`.** The title page lives in `app_data`
   (`wordsmith.titlePage`): title, credit ("Written by"), authors, source
   ("Based on …"), draft date, contact, copyright and notes, as text. Layout
   from convention: title centered about a third of the way down, credit and
   authors below it, source below them, contact at the foot on the left, draft
   date and copyright at the foot on the right. The page view shows the
   script; PDF export and printing put the title page first as a section of
   its own, with the script's page numbers starting at 1 after it. A dialog
   edits the fields (one undo step). Fountain reads and writes the title page
   keys; the native format keeps it through `app_data`.
2. **`m5/headers`.** Header and footer settings in `app_data`
   (`wordsmith.headerFooter`): left, center and right text for each, with
   fields `{page}`, `{scene}`, `{date}`, `{revision}`, `{title}`, and whether
   page 1 shows them. Default: `{page}.` on the right of the header, none on
   page 1 (as today). `{page}` is a PAGE field, `{scene}` a STYLEREF to the
   scene heading style (so each page shows its own scene), `{date}` today's
   date (or a fixed date), `{title}` the title, `{revision}` the current
   revision set's name (M6). A dialog edits them.
3. **`m5/scenes`.** Scene commands: move a scene (or several) before another,
   set a heading, set a scene's summary (its Summary paragraph). Index cards:
   a grid of cards, one per scene, with the heading and the summary (or the
   scene's first action); drag to reorder, double-click to go to the scene.
   Scene view: the scenes as blocks of their text, in order; drag to reorder.
   Both edit the one script through commands; undo restores the order.
4. **`m5/tables`.** A side panel with two tables. Scenes: number, heading,
   page, length in lines (eighths in M6), characters in the scene, summary;
   heading and summary cells edit the script; dragging rows reorders scenes.
   Characters: name, speeches, scenes, first scene; editing a name renames
   the character everywhere (`character.rename`: cues keep their extensions,
   the name in action and dialogue changes as a whole word keeping its case
   style, the autocomplete list follows). Each table exports as CSV.
5. **`m5/notes`.** Notes are the document's comments: a note is anchored to a
   range of text, which edits keep in place. Commands to add a note to the
   selection, edit, delete and list; the page view marks noted text and a
   popover edits the note; the tables panel lists notes. The native format
   gains note anchors and the notes themselves (a format version step with a
   migration, documented in `docs/format.md`); Fountain writes notes as
   `[[ ]]` where they are anchored.

## Tests

- Title page: fields stored and undone; PDF has the title page first and the
  script numbered from 1 after it; Fountain round trip of the keys; an empty
  title page prints nothing.
- Headers: each field on the right pages (scene changes page to page), first
  page rule, fixed date; golden PDFs unchanged with the default header.
- Scenes: moving scenes (one, several, to the end, before text before the
  first heading), undo, headings and summaries; editor tests for card drags.
- Tables: rows and cells, editing cells, row reorder, CSV escaping; rename
  with extensions, case styles, whole words only, undo as one step.
- Notes: anchors survive typing around them and deleting part of the range;
  native round trip and migration from format 1; Fountain output; hostile
  note data.
