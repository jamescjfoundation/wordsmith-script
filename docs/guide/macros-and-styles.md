# Macros and text styles

## Macros

A script has twenty macro slots (Tools › Macros). A macro can:

- make the paragraph an element (Scene Heading, say),
- type some text (a line break acts as Return),
- then start a new paragraph of another element.

Run a macro from its shortcut, from Tools › Run Macro, or by typing its
**alias**: a word that is replaced with the macro's text when you finish the
word. Options: match the alias's capitals, ask first, whole word only, match
case, and the elements the macro works in.

New scripts come with ten macros on Mod+Alt+Shift and a digit: 1 INT., 2 EXT.,
3 DAY, 4 NIGHT, 5 CONTINUOUS, 6 and 7 parentheticals, 8 CUT TO:, 9 DISSOLVE
TO:, 0 FADE OUT. "Copy from a script…" replaces a script's macros with another
script's.

## Text styles

Mod+B, Mod+I and Mod+U make text bold, italic or underlined. Format › Text
Style also has double, word and dotted underlines, strike through, raised and
lowered text, capitals and small capitals, small letters, and Plain Text
(Mod+Shift+T) to remove them. Format › Highlight has twelve named colors and
any other; Format › Text Color sets the ink.

With nothing selected, a style applies to what you type next.

Element Settings can give an element its own color, highlight, strike through
or small letters, and "Template Formatting for All" puts every element back to
the screenplay template's formatting.
