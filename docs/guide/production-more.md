# More production tools

## Dual dialogue

Put the caret in the second of two speeches in a row and choose Format › Dual
Dialogue (Mod+Shift+D). The two speeches print side by side. In Fountain files
this is a `^` after the second name. Edit the second speech in the normal or
draft view.

## Scene numbers

Production › Scene Numbers…: start at any number, start again every so many
scenes, letter added scenes 1A or A2, show the numbers on either side or both,
give them their own font, set one scene's number by hand, and renumber
everything, from the caret on, or only scenes without a number.

## Locked pages

Production › Locked Pages adds: Relock (number 1, 2, 3 again from where pages
break now), Lock New Page Here, Unlock This Page, and Move Page Start Up or Down
a paragraph. Edit a locked page's number with `lock.setLabel` from the command
palette or an agent.

## Revisions

The Revision Sets window can give each set its own margin mark and can show only
the current set. Production › Next and Previous Revised Text step through
revised text.

## Track changes

Production › Track Changes (Mod+Shift+C): what you type is marked as inserted
and what you delete stays, struck through, until accepted or rejected. Each
change remembers who made it and when (your name is in Preferences). Step
through changes and accept or reject them one at a time or all at once.

## Comparing versions

Production › Compare with Another Version…: pick the earlier version. The
comparison opens as a new script: added text marked as inserted, removed text as
deleted, and moved scenes with a note saying where they were.

## Printing

File › Print… chooses everything, a range of pages or scenes, revised or
unrevised pages or one revision set, copies (collated), last page first, the
title page, and revision marks. Sides for a character print only their scenes,
with the scene numbers they have in the full script and the name on every page.
Preview opens the pages in your PDF viewer.

## Watermark

Production › Watermark… prints text across every page, at the strength you
choose, with the name of who the copy is for.

## Headers and footers

The Header and Footer window adds a first page number, the footer on page 1
apart from the header, and the `{collated}` field: every revision set in the
script.
