# Getting started

Open Wordsmith Script and you have a blank script with the caret in a scene
heading.

1. Type `int`, press **Tab**: the heading becomes `INT. `, ready for the
   place. Type `kitchen`, press **Tab** again for ` - `, and type `night`.
2. Press **Return**. You are in Action. Describe what we see.
3. Press **Return** and then **Tab**: the new paragraph becomes a Character.
   Type a name; it is set in capitals.
4. Press **Return**: Dialogue. Type the line. Return again goes back to
   Action; Tab instead gives you a Parenthetical.

That is most of it: Return picks the element that usually comes next, Tab
picks the other likely one, and you never set indents by hand. If the
element is wrong, choose another from the toolbar, the Format menu, the
right-click menu, or with **Mod+0** to **Mod+9** (Mod is Command on macOS,
Control elsewhere).

Save with **Mod+S**. Scripts are `.wss` files; the first save asks where.
Export a PDF with **Mod+Shift+E**, or print with **Mod+P**.

When you want to look at the script differently, the View menu has the
index cards, the scene view, the story board, the outline and the tables
panel. See [Views](views.md).
