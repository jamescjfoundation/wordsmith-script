# M2 plan: pagination and page view

Date: 2026-11-19

## Scope

From the kickoff: the screenplay template with the spec's geometry defaults
(done in M1); keep Character with its first line of Dialogue; never strand a
Scene Heading at the foot of a page; split Dialogue and Action only at
sentence boundaries, with (MORE) and (CONT'D); automatic character CONT'D
within a scene; scene (CONTINUED) as an option; page numbers top right with a
period, none on page 1; exact PDF export with selectable text through
`wordsmith-pdf`; printing through craft-print; golden tests comparing page
breaks and PDF text for at least three public-domain screenplays transcribed
into Fountain.

Spec items (all from `docs/SPEC.md`):

| Spec item | Status in spec |
| --- | --- |
| Dialogue split across a page: (MORE) at the bottom, character name with (CONT'D) at the top of the next | Sourced |

| Line spacing presets change page count; default to one page per minute | Sourced |

## Approach

**Our own paginator, the layout engine's line breaks.** `wordsmith-layout`
is a Word-style multi-pass paginator. Teaching its core screenplay rules is
the riskiest possible change, so pagination happens in `wordsmith-script`
instead:

1. Lay out the script once (print view) and read each paragraph's lines and
   their byte ranges from the layout. Line breaking does not depend on
   pagination, and every element sits on the 12 pt grid, so a page is a sum
   of line heights.
2. Fill pages with the screenplay rules: space before is dropped at the top
   of a page; keep-with-next chains (Scene Heading with what follows,
   Character with its Parenthetical and first Dialogue line); start new page;
   paginate-as; Action and Dialogue split only after a sentence, with at
   least two lines on each side; speeches broken across pages get (MORE)
   and the name with (CONT'D); optional scene CONTINUED lines.
3. Build an output script from the plan: the source paragraphs with explicit
   page breaks, split paragraphs, the inserted (MORE), (CONT'D) and CONTINUED
   lines, automatic CONT'D on repeated speakers, and a header holding the page
   number. Keep rules are switched off in the output, because the breaks are
   already decided.
4. Lay the output out with `wordsmith-layout` and check that its pages are
   exactly the plan's. A mismatch is a bug and fails the tests.
5. The output carries a map from each output paragraph back to its source
   paragraph and byte offset, so the page view can show the paginated script
   while the caret, selection and clicks work on the source.

PDF export renders the output script through `wordsmith-pdf`; printing hands
that PDF to craft-print (v0.1.0 crate, pinned like the other craft-libs
crates).

**Golden tests.** Three public-domain screenplays (or long excerpts),
transcribed into Fountain by hand, with sources recorded in
`docs/provenance.md`. This needs a Fountain reader now; M4 extends it to the
full format and adds the writer. Golden files hold each page's first and last
lines and the PDF text, reviewed by eye once and then compared on every run.

## Branches

1. `m2/paginate`: the paginator and the output script, with unit tests.
2. `m2/page-view`: the editor shows the paginated script; caret mapping.
3. `m2/pdf`: PDF export (command and CLI), printing.
4. `m2/golden`: Fountain reader subset, three transcribed scripts, golden
   tests.

## Decisions to record

The rules above that the spec leaves open (minimum lines on each side of a
split, what counts as a sentence end, CONTINUED placement, how CONT'D is
detected and when it is not added, the More/Continued settings and defaults),
in `docs/decisions/0012-pagination.md`.

## Tests

- Unit tests on small scripts for each rule: top-of-page space, stranded
  headings, Character with Dialogue, sentence splits with (MORE)/(CONT'D),
  speeches broken between paragraphs, no valid split, start new page,
  automatic CONT'D within a scene and not across scenes, CONTINUED option,
  page numbers.
- The plan and the laid-out output agree page by page, on every test script.
- Hostile input: a single paragraph longer than a page, an unbreakable
  sentence, an empty script, thousands of pages.
- PDF: the text extracted from the PDF matches the plan's pages.
- Performance: paginating a 150-page script, measured and recorded.
