# M19 plan: polish

Date: 2026-11-20. Part of `docs/history/plans/v0.3-ui.md`.

Deliverables:
- **Key tips** (from M15).
- **A first-run tour:** five steps pointing out the ribbon, the elements, the
  Navigator, the Inspector and the File page; it can be skipped and does not
  come back.
- **The window's layout in the preferences:** the open panels and their widths,
  the ribbon shown in full or as tabs, and the menu bar.
- **README and guide:** the README pictures redone by the offscreen renderer,
  with the ribbon, panels and File page; a guide page for the window.
- **Typing measured again** at 150 pages.

Tests: the layout and the tour keep through the preferences, and bad values are
bounded; every earlier UI test passes.

Typing at 150 pages, two runs: median 17.2 to 17.4 ms with everything shown,
15.2 to 16.3 ms without the side panels, and 16.0 to 17.1 ms with no chrome at
all (focus mode). The machine measured slower overall than at M16, so the useful
figure is the difference: the ribbon and panels cost about 1 ms a keystroke
(`WS_TIMING_PARTS=1`).

Status: done (2026-11-20). Not done:
- Tooltips carry a line from the ribbon, not a description from every command
  in the registry.
- The usability pass with the owner is the review that follows.
